This code accompnaies the paper "Offshore wind development creates emerging conflicts with globally important biodiversity areas" by Caitlin D. Kuempel, Maxence Fontaine, and Jackson Stockbridge.

Raw data needed to recreate the analysis can be downloaded or requested from the following sources:

[Ecologically and Biologically Significant Marine Areas (EBSAs)](https://wwf-sight-maps.org/arcgis/rest/services/Global/Ecologically_or_Biologically_Significant_Marine_Areas/MapServer)

[Key Biodiversity Areas (KBAs)](https://www.keybiodiversityareas.org/request-gis-data)

[World Database on Protected Areas](https://www.protectedplanet.net/en)

[Marine Wilderness](https://knb.ecoinformatics.org/view/doi:10.5063/F1RR1WFT)

[Offshore wind infrastructure](https://figshare.com/articles/journal_contribution/Satellite_mapping_reveals_extensive_industrial_activity_at_sea_-_analysis_data/24309475)


The codes should be run in numerical order as depicted in the code names.
